# Frontend — Лабораторная работа 1 (DevOps)

Веб-приложение на Flask с HTML-шаблоном. Отправляет данные на отдельный
бэкенд-сервис через HTTP-запросы.

## Версии

| Тэг  | Содержимое                                                                 |
|------|---------------------------------------------------------------------------|
| v1.0 | Поле ввода и кнопка «Отправить», отправка текста на бэкенд через `POST /api/data` |
| v2.0 | Дополнительно второе поле и кнопка «Показать данные», вывод ответа бэкенда в отдельное поле |

## Установка и запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Страница доступна по адресу <http://127.0.0.1:5000>.

## Связь с бэкендом

Адрес бэкенда задается переменной окружения `BACKEND_URL`, значение по
умолчанию — `http://127.0.0.1:5001`.

```bash
# Windows PowerShell
$env:BACKEND_URL = "http://127.0.0.1:5001"; python app.py
# Linux/macOS
BACKEND_URL=http://127.0.0.1:5001 python app.py
```

Страница обращается к API по относительному пути `/api/...`. Запросы
`/api/*` принимает встроенный обратный прокси `api_proxy` и переправляет
их на `BACKEND_URL`. Это позволяет запускать бэкенд без публикации его
порта наружу: контейнеры общаются между собой по внутренней сети Docker,
а браузер работает только с фронтендом.

## Запуск в Docker

Сборка образа версии 2.0:

```bash
docker build -t frontend:2.0 .
```

Запуск контейнера (в контейнере адрес бэкенда — имя сервиса в сети Docker):

```bash
docker run -d --name frontend -p 5000:5000 \
  -e HOST=0.0.0.0 -e BACKEND_URL=http://backend:5001 frontend:2.0
```

В рамках лабораторной работы сервис запускается через `docker compose`
из репозитория DevOps.

### Переменные окружения

| Переменная    | По умолчанию          | Назначение                                     |
|---------------|-----------------------|------------------------------------------------|
| `BACKEND_URL` | `http://127.0.0.1:5001` | адрес бэкенда (в Docker — `http://backend:5001`) |
| `HOST`        | `127.0.0.1`           | адрес прослушивания (в Docker — `0.0.0.0`)     |
| `PORT`        | `5000`                | порт сервиса                                   |
