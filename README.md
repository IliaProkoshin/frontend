# Frontend — Лабораторная работа 1 (DevOps)

Веб-приложение на Flask с HTML-шаблоном. Отправляет данные на отдельный
бэкенд-сервис через HTTP-запросы.

## Версии

| Тэг  | Содержимое                                                                 |
|------|---------------------------------------------------------------------------|
| v1.0 | Поле ввода и кнопка «Отправить», отправка текста на бэкенд через `POST /api/data` |
| v2.0 | Дополнительно второе поле и кнопка «Показать данные», вывод ответа бэкенда в отдельное поле |

## Установка и запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Страница доступна по адресу <http://127.0.0.1:5000>.

## Связь с бэкендом

Адрес бэкенда задается переменной окружения `BACKEND_URL`, значение по
умолчанию — `http://127.0.0.1:5001`.

```bash
# Windows PowerShell
$env:BACKEND_URL = "http://127.0.0.1:5001"; python app.py
# Linux/macOS
BACKEND_URL=http://127.0.0.1:5001 python app.py
```

Значение передается в шаблон и используется скриптом
`static/js/script.js` для формирования запросов. Бэкенд должен разрешать
CORS-запросы (в проекте backend подключен `flask-cors`).

## Структура проекта

```
frontend/
├── app.py                 # точка входа Flask, рендеринг шаблона
├── requirements.txt
├── templates/
│   └── index.html         # страница с формой
└── static/
    ├── css/style.css      # стили страницы
    └── js/script.js       # логика отправки запросов на бэкенд
```
